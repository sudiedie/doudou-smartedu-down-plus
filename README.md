# 国家中小学智慧教育平台资源下载器

专门用于国家中小学智慧教育平台 (`smartedu.cn`) 电子课本、课程视频、课件资源的自动识别与合并下载。

## 项目来源

本项目基于 [undsky/doudou-smartedu-down](https://github.com/undsky/doudou-smartedu-down) 修改。

- 原作者：[undsky](https://github.com/undsky)
- 原作者网站：[www.undsky.com](https://www.undsky.com)
- 本版本改进：资源勾选与批量下载、指定保存文件夹、同名文件自动加序号。

感谢原作者提供原项目。原项目当前未见明确的许可证文件，本说明用于标明来源，不替代原作者的使用或分发授权。

## 改进功能：勾选下载与选择保存文件夹

每项资源左侧增加复选框，顶部提供“全选”和“取消全选”，底部显示已选数量和“下载已选”按钮。默认不勾选资源，选择之后才可批量下载。

点击资源标题也可勾选。视频清晰度分别可选，例如只勾选720p就只下载720p；若勾选多个清晰度，则分别下载所选版本。重新扫描或收起面板时保留勾选，切换课程时清空勾选。

点击“下载已选”后，会立即弹出文件夹选择框。选定文件夹，并在浏览器提示时允许保存，本次所有勾选的课件、作业和视频都会写入该文件夹；每次批量下载都可重新选位置。取消选择不会启动下载，勾选会保留。遇到同名文件时自动增加序号，例如 `课件 (2).pdf`。

文件夹选择使用 Edge/Chrome 的文件系统接口，需要在新版桌面浏览器中使用。若无法选择或写入文件夹，插件会显示原因，不会自动把批量资源保存到其他位置。面板中每项资源原有的“下载”按钮仍按浏览器默认方式保存。

若此文件夹已加载到Edge：打开 `edge://extensions/`，对该扩展点击重新加载，再刷新智慧教育平台网页，新界面才会生效。若安装时选择的是其他副本，请改为加载当前包含 `manifest.json` 的文件夹。

## 🚀 安装与运行扩展 (Chrome / Edge / Brave / 360 等)

1. 打开浏览器扩展管理页面 (例如 Chrome 输入 `chrome://extensions/`)；
2. 开启右上角的 **“开发者模式” (Developer Mode)**；
3. 点击 **“加载已解压的扩展程序” (Load unpacked)**；
4. 选择本插件；
5. 打开 [国家中小学智慧教育平台](https://www.smartedu.cn/) 任意电子课本或视频详情页，右侧即会自动出现资源下载悬浮球与控制面板！
